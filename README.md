## 🎯 Overview

This is my personal portfolio website built with **Next.js 15** and **TypeScript**, showcasing my skills, experience, and projects as a Frontend Developer. The site features a modern design with smooth animations, responsive layout, and interactive elements.

### Key Highlights:
- 🎨 **Modern Design**: Clean, professional interface with glassmorphism effects
- 📱 **Fully Responsive**: Optimized for all devices and screen sizes
- ⚡ **High Performance**: Fast loading times with Next.js optimizations
- 🎭 **Interactive Elements**: Smooth animations and hover effects
- 🌙 **Dark Theme**: Elegant dark theme with gradient accents

## ✨ Features

- **Hero Section**: Dynamic typing animation and professional introduction
- **Skills Showcase**: Interactive skill cards with proficiency indicators
- **Work Experience**: Detailed timeline of professional experience with project highlights
- **Project Portfolio**: Showcasing personal and professional projects with live demos
- **Education & Achievements**: Academic background and certifications
- **Contact Integration**: Direct links to email, phone, GitHub, and LinkedIn
- **Responsive Design**: Seamless experience across desktop, tablet, and mobile
- **Modern Animations**: Smooth transitions and micro-interactions
- **SEO Optimized**: Meta tags and structured data for better search visibility

## 🚀 Getting Started

### Prerequisites

- **Node.js** (v18 or higher)
- **npm** or **yarn**

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/anik511/my-portfolio.git
   cd my-portfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   # or
   yarn install
   ```

3. **Run the development server**
   ```bash
   npm run dev
   # or
   yarn dev
   ```

4. **Open your browser**
   
   Navigate to [http://localhost:3000](http://localhost:3000) to see the portfolio.

### Build for Production

```bash
npm run build
npm start
```
